<h3 align="left">🚀 Featured Projects:</h3>

- 🔐 **[Secure Agentic AI Work OS](https://github.com/VineetBESTMAN/secure-agentic-work-os)**  
  A secure multi-tenant AI copilot system combining **RAG, LangGraph-based agent workflows, MCP tools, human approvals, RBAC, OAuth/OIDC, pgvector, Redis, Docker and production-oriented AI security controls**.

- ♟️ **[Real-Time Chess Move Detection](https://github.com/VineetBESTMAN/real-time-chess-move-detection)**
